# NeuroNexus Web Development - Landing Page Project

## Project Description
This project is focused on creating a simple **Google Form-like web form** using only **HTML** and **CSS**. The objective was to build a landing page that collects user data through various form elements, with no JavaScript used.

## What I Have Done
- Created a **web form** that collects the following information:
  - Full Name (Text Input)
  - Contact Number (Phone Input)
  - Address (Multiline Textarea)
  - Company Name (Text Input)
  - Email Address (Email Input)
  - Department (Dropdown/Select Menu)
  - Gender (Radio Buttons: Male, Female, Prefer not to say)
  - Submit Button
  
- Implemented **bonus features**:
  - Added **hover effect** on the submit button for better user interaction.
  - Set a **different background color** for the form to make it stand out from the page background.
  - Added a **minimal box-shadow** to the form for improved visual appeal.
